## The entry

One line, 118 characters — a voicemail greeting as if a cat recorded it:

> You've reached Mochi. If you're calling about the vase, I did it. If you're calling about dinner, I'm listening. Beep.

## How it was chosen

`main.py` writes 10 fresh candidates and scores each against the judge's
published criteria, in order — reads as a cat's voicemail greeting and lands
a laugh; joke specific to cats; the cat has a clear voice of its own; works
spoken aloud with a quick punch; fresh wording — with weights 5/4/3/2/1.
The winner scored 74/75, the highest of the ten; the runner-up scored 72/75.

Run it:

```sh
python3 main.py
```

It writes the winning line to `/output/entry.txt`, validated against the
gate: UTF-8 text, 1–120 characters, a single line.
